## 3. รายละเอียดสิ่งที่เพิ่ม (ไม่เปลี่ยนการทำงานเดิม)

1. **แคชข้อมูลอากาศ (UC-10/11 A1)** — `AirQualityData.fromCache`, `AirQualityService.canUseCache()`; ถ้าไม่มีแคชยังโยน error เหมือนเดิม (E1)
2. **คะแนนค่าประมาณ (UC-14 A1/E1)** — ถ้า API สภาพอากาศหรือฝุ่นล่มตัวใดตัวหนึ่ง: ใช้แคช → ถ้าไม่มีใช้ค่ากลาง (AQI 50 / 30°C) แล้วเพิ่มบรรทัด “ℹ️ คะแนนเป็นค่าประมาณ…” ในรายการเตือน; ล่มทั้งสองตัวยังแจ้งว่าคำนวณไม่ได้เหมือนเดิม
3. **คำเตือนความเสี่ยง (UC-13)** — เมื่อคะแนน 0–39 ทั้งเส้นทางที่วางเองและวงรอบโซน แสดงป๊อปอัปพร้อมเหตุผล 4 ข้อแรก, ปุ่ม “ดูเส้นทางอื่น” (ล้างเส้นทางให้เลือกใหม่) และ “รับทราบ”; บันทึกลง `risk_warnings` ทุกครั้ง (`ack` / `other` / `dismissed`)
4. **เส้นทางโปรดในบัญชี (IT-08)** — ยังเก็บในเครื่องเหมือนเดิม และรวมกับที่อยู่ใน Firestore
5. **กันลบเส้นทางที่ใช้อยู่ (UC-08 E2)** — นับผู้ใช้ที่มีเส้นทางนี้ใน `savedRoutes`
6. **จัดการบัญชีผู้ใช้** — แดชบอร์ดแอดมิน → ปุ่ม “จัดการผู้ใช้” → ค้นหา / ระงับ (ใส่เหตุผล) / คืนสิทธิ์; ระงับบัญชีแอดมินไม่ได้; บัญชีถูกระงับเห็นหน้าแจ้งเหตุผล + ปุ่มออกจากระบบ (ถ้าอ่านสถานะไม่ได้ จะเข้าแอปตามปกติ ไม่ขวางผู้ใช้)
7. **บันทึกค่าฝุ่นจากหน้าคุณภาพอากาศ (IT-04)**
8. **SOS เลือกโทร/SMS (UAT-04)** — ถ้าไม่มีพิกัด โทรออกทันทีเหมือนเดิม
9. **unit test ใหม่** `test/thesis_gap_test.dart` (แคช 4 กรณี + UC-04 A1 + UC-13 เกณฑ์)

### ⚠️ ต้องทำเองหลังรับงาน
- **Deploy กฎ Firestore**: `firebase deploy --only firestore:rules` — จำเป็นสำหรับ `risk_warnings` และการระงับบัญชี (ถ้ายังไม่ deploy ฟีเจอร์อื่นยังทำงานปกติ แค่บันทึกคำเตือน/ระงับบัญชีจะไม่สำเร็จ)
- ถ้าจะใช้ query `savedRoutes` เยอะ Firestore อาจขอสร้าง index — ปกติ array-contains-any ฟิลด์เดียวไม่ต้องสร้าง

## 5. จุดที่ควรแก้ในเล่มให้ตรงกับระบบ

1. **ตาราง 3.16** ช่วง “ควรระวัง” พิมพ์เป็น `[40]-[60]` → ควรเป็น **40–69** (โค้ดและข้อความอื่นในเล่มใช้ 40–69)
2. **IT-08** บรรยายว่ารหัสผ่าน “อย่างน้อย 6 ตัวอักษร” → ปัจจุบันเป็น **8–64 ตัว ต้องมีตัวพิมพ์ใหญ่/เล็ก ตัวเลข สัญลักษณ์** และล็อกเมื่อผิด 5 ครั้ง (`password_policy.dart`)
3. **3.3.5 สมการ 3.2** — T(t) กลางคืนในโค้ดคือ `0.7 + 0.3 × สัดส่วนเส้นทางที่มีไฟส่องสว่าง` (ยังอยู่ในช่วง 0.7–1.0 ตามเล่ม) ควรบรรยายเพิ่ม และ S_trf ใช้ข้อมูลถนนสายหลัก/ทางเท้า/แยกไฟจาก OSM
4. **5.2.2.2** อ้างค่า “6.4 กม. ≈ 45 นาที” — โค้ดปัจจุบันใช้ 6 นาที/กม. (วิ่ง) และ 3 นาที/กม. (ปั่น) + เวลาขึ้นเนิน และผู้ใช้ปรับเองได้ (UC-04 A1)
5. **3.4.2** แหล่งข้อมูลคุณภาพอากาศ → Open-Meteo (ดูข้อ 4)
6. บทที่ 4 ยังไม่มีผลทดสอบของฟีเจอร์ที่มีในแอปแต่ไม่อยู่ในเล่ม เช่น โซนวิ่ง 13 โซน, Safety Dijkstra, เตือนออกนอกเส้นทาง, แก้ไขกิจกรรมย้อนหลัง, นำเข้าไฟล์ TCX — ถ้าจะใส่ในเล่มควรเพิ่มใน 3.2 และบทที่ 4
